Project 02 · Infrastructure as Code
AWS VPC — Three-Tier Defense in Depth
A production-grade, multi-tier VPC on AWS built entirely with Terraform. Security designed into the architecture with genuine isolation between tiers. Deployed without touching the AWS console. Full rebuild in under 3 minutes.
Three-tier network: Public (10.0.1/2.0/24) → Private (10.0.10/20.0/24) → Data (10.0.100/200.0/24)
Security group chaining: nginx-sg → app-sg → db-sg using SG ID references, not CIDRs
NACLs at subnet boundary with explicit DENY on data tier (belt-and-braces defense)
VPC Flow Logs to CloudWatch (7-day) + S3 (30-day, AES-256 encrypted)
Free-tier substitutions: NAT Instance replaces NAT Gateway (~$64/mo saved), Nginx replaces ALB (~$18/mo)
